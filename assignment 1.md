What happens between typing a URL and seeing the page?
Ans- Jab ham koi URL type karte hain, toh browser DNS ka upyog karke website ka IP address dhoondhta hai aur server ke saath ek secure connection banata hai. Iske baad, vah us server se website ka code (HTML/CSS) maangta aur download karta hai. Ant mein, browser is code ko process karke aapki screen par visual webpage dikhata hai.
